# 六级 8000 词

在线打开：<https://zch6a.github.io/cet6-8000/>

一份面向大学英语六级（CET-6）的 8000 词表网页，打开就能用，不用安装，也不用登录。

- **真题词频**：统计了 2021 年 6 月到 2026 年 6 月共 13 次六级考试的真题文本，包括听力原文、阅读、写作题目和翻译参考译文。统计前剔除了每份试卷都有的题目说明，词形变化合并到原形计数。
- **三种浏览方式**：按字母顺序、按真题出现频率、只看「会写词汇」（写作和翻译里要会拼会用的词）。
- **每个词**：简写词性，只留考试常考的意思，再配一句助记。助记优先用词根词缀，也有联想、形近对比和谐音，另有词根积木示意图、emoji 画面、易混词和同根词。
- **背诵模式**：按间隔重复安排复习，忘了的词会反复出现。可以填考试日期，自动算出每天该背多少。
- **自测**：看词选义、看义拼词、听音辨义。
- **导出 PDF**：当前列表一键导出为双栏打印版。

背诵进度只保存在你自己的浏览器里（localStorage），换浏览器或清除网站数据后会重置。

## 说明

- 词条与级别标签来自开源词典 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 协议）。
- 真题原文只用于统计词频，不收录在本仓库中。
- 助记仅用于帮助记忆，不一定是严格的词源。

## 文件

- `index.html`：网页本体
- `data/a.js` … `data/z.js`：按首字母分开的词表数据
- `data/meta.js`：统计说明
