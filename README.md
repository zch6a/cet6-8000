# 六级 8000 词

在线打开：<https://zch6a.github.io/cet6-8000/>

一份面向大学英语六级（CET-6）的 8000 词表网页，打开就能用，不用安装，也不用登录。手机、电脑都能用。

## 内容

- **真题词频**：统计了 2021 年 6 月到 2026 年 6 月共 13 次六级考试的真题文本，包括听力原文、阅读、写作题目和翻译参考译文。统计前剔除了每份试卷都有的题目说明，词形变化合并到原形计数，英美两种拼法（colour / color）算同一个词。
- **每个词**：简写词性，只留考试常考的意思。每个词都配一句助记：优先用词根词缀，也有联想、形近对比、谐音和来历。
- **词根积木和动画**：能拆的词显示彩色的前缀 / 词根 / 后缀积木，点「▶ 动画」看这个词是怎么拼出来的；「词根拆解」里还列出同根词。
- **串记**：500 多组。形近词（adopt / adapt / adept）配一句区分口诀和一个小段子；翻译话题词（二至二分、四大发明、春节…）串成一句翻译式例句。
- **熟词僻义**：400 多个熟词标出考试常考的冷门意思，如 address「处理」、fine「罚款」，可以单独筛出来看。
- **翻译话题词**：针灸、兵马俑、碳中和、共享单车这类中国文化和社会热点词，可以单独筛出来背。
- **写作换词**：会写词附写作、翻译能直接用的搭配，详情里列出同词性、同意思的近义词。

## 功能

- **五种浏览方式**：按字母、按真题频率、只看会写词汇、按词根、按串记；可按级别、频率、首字母筛选，可中文反查。
- **简化版**：默认收起词根积木，点「词根拆解 ▸」再展开，页面更清爽。
- **背诵**：间隔重复安排复习，忘了的词本轮会再出现；填上考试日期，自动算出每天该背多少。手机上可以轻点卡片看答案，左滑「忘了」、右滑「记得」。
- **快速过词**：自动播放，看词、听音、亮出意思和助记，不打分。
- **自测**：看词选义、看义拼词、听音辨义、易混辨析。答错的词自动加入复习。
- **导出 PDF**：当前列表一键导出为双栏打印版。

背诵进度只保存在你自己的浏览器里（localStorage）。换设备或清除网站数据前，可以在「背诵」页导出进度文件，换到新设备上再导入。

## 说明

- 词条与级别标签来自开源词典 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 协议）。
- 真题原文只用于统计词频，不收录在本仓库中。
- 助记仅用于帮助记忆，不一定是严格的词源。

## 文件

- `index.html`：网页本体
- `data/core.js`：先加载的词表核心数据（单词、释义、词根）
- `data/extra.js`：随后加载的助记、串记和真题分布
- `data/a.js` … `data/z.js`、`data/meta.js`：按首字母分开的完整数据，生成 PDF 时使用
- `sw.js`：离线缓存，第二次打开几乎瞬间加载
